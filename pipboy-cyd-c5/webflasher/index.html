PIP-OS FIRMWARE INSTALLER — NM-CYD-C5

Connect the NM-CYD-C5 via its ESP32-C5 programming USB-C port (the board has two USB-C ports — use the one wired to the C5, not the CH340 UART-only port), then press the button below.

Your browser does not support Web Serial. Use Chrome, Edge, or Opera. Web Serial is blocked here — this page must be served over HTTPS (or http://localhost).
  • If no device appears in the browser's port picker, install the CH340/USB-CDC driver for your OS and reconnect.
  • Hold BOOT while tapping RESET first if the board doesn't enter download mode automatically (older esptool auto-reset timing can be flaky on some ESP32-C5 boards).
  • Flashing erases the whole app partition; SD card contents are untouched.
